# Manaphy + Phione Event

Bring Manaphy and Phione into the FireRed and LeafGreen postgame with a small event built around the Pokémon Day Care.

After becoming Champion, return to the **Route 5 Day Care** to receive a special **Manaphy Egg**. Hatch Manaphy and pair it with Ditto at the Day Care to obtain **Phione Eggs**, recreating Manaphy's unusual breeding relationship in Kanto.

## Features

- Post-Champion Manaphy Egg gift
- Uses the existing Route 5 Pokémon Day Care
- Manaphy can breed with Ditto to produce Phione
- Manaphy Egg can only be received once
